# Our Little Universe

اسکلت اولیه سایت سورپرایز تولد مائده.

## اجرا

این پروژه از JavaScript ماژولار استفاده می‌کند. برای اجرای محلی، فایل‌ها را با یک local server باز کن؛ مثلاً:

```bash
python -m http.server 8000
```

سپس وارد `http://localhost:8000` شو.

## موارد آماده

- صفحه شمارش معکوس تا ۱۹ اکتبر ۲۰۲۶ ساعت ۰۰:۰۰ به وقت ایران
- ورود اختیاری قبل از پایان تایمر
- صفحه رمز با حساسیت‌نداشتن به حروف بزرگ و کوچک
- ساختار ۵ فصل
- ناوبری قبلی/بعدی
- طراحی اولیه موبایل‌اول

## موارد مرحله بعد

- انیمیشن واقعی دروازه
- شخصیت‌های کو و فوتابا
- سیستم ورق‌زدن کتاب
- ورود خاطرات واقعی و تصاویر
- پخش‌کننده موسیقی
- نامه پایانی
- ذخیره پیشرفت و انتشار GitHub Pages
